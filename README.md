# ห้องโครงงาน PBL (รูปแบบที่ 3)

เว็บแอปสำหรับเรียนวิชาโครงงานแบบโครงงานเป็นฐาน รูปแบบที่ 3 คือเลือกเฉพาะหน่วยที่เหมาะสมในรายวิชามาจัดแบบโครงงาน ส่วนหน่วยอื่นสอนตามปกติ อ้างอิงโครงสร้างจากคู่มือ Prompt AI วิชาโครงงาน สำหรับครูและผู้เรียนอาชีวศึกษา ปวช./ปวส. ทำงานบน Google Apps Script และใช้ Google Sheet เป็นฐานข้อมูล

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | ระบบหลังบ้านบน Google Apps Script (ฐานข้อมูล Sheet, เข้าระบบ, สิทธิ์ของนักศึกษา/ครู/ผู้ดูแล) |
| `Index.html` | หน้าเว็บทั้งหมด รวมเนื้อหา 6 ขั้นและ 11 ขั้นพร้อม Prompt |
| `build/mock.js` | เซิร์ฟเวอร์จำลองพร้อมข้อมูลตัวอย่าง ใช้กับหน้าตัวอย่างเท่านั้น |
| `build/build.py` | สร้าง `docs/index.html` (รันใหม่ทุกครั้งที่แก้ `Code.gs` หรือ `Index.html`) |
| `docs/index.html` | หน้าตัวอย่างที่ใช้งานได้ในเบราว์เซอร์ทันที ข้อมูลเก็บในเบราว์เซอร์เท่านั้น |

# คู่มือติดตั้ง

ระบบมี 2 ไฟล์ คือ `Code.gs` (ระบบหลังบ้าน) และ `Index.html` (หน้าเว็บ) ทำงานบน Google Apps Script และบันทึกข้อมูลลง Google Sheet "ฐานข้อมูลวิชาโครงงาน"

## ขั้นตอนติดตั้ง (ประมาณ 10 นาที)

1. เปิด Google Sheet: https://docs.google.com/spreadsheets/d/1ilNfGxlgNwWVAMvf8M8RRh5FqHnLqxqZ-c1_Xc2tgRw/edit
2. ไปที่เมนู **ส่วนขยาย > Apps Script**
3. ในไฟล์ `Code.gs` ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาไฟล์ `Code.gs`
4. กดปุ่ม **+** ข้าง "ไฟล์" > **HTML** ตั้งชื่อว่า `Index` (ตัว I พิมพ์ใหญ่ ไม่ต้องใส่ .html) แล้ววางเนื้อหาไฟล์ `Index.html`
5. กดบันทึก (ไอคอนแผ่นดิสก์)
6. เลือกฟังก์ชัน **setupSheets** ในแถบด้านบน แล้วกด **เรียกใช้ (Run)**
   - ครั้งแรก Google จะขอสิทธิ์ ให้กด "ตรวจสอบสิทธิ์" > เลือกบัญชี > "ขั้นสูง" > "ไปที่โครงการ (ไม่ปลอดภัย)" > "อนุญาต"
   - ระบบจะสร้างแผ่นงาน 6 แผ่นใน Sheet ให้อัตโนมัติ
7. กด **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่**
   - เลือกประเภท: **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
8. กด "ทำให้ใช้งานได้" แล้วคัดลอก **URL ของเว็บแอป** ไปแจกนักศึกษาและครู

> เมื่อแก้ไขโค้ดภายหลัง ต้องไปที่ **ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข (ไอคอนดินสอ) > เวอร์ชัน: เวอร์ชันใหม่** แล้วกดทำให้ใช้งานได้ ลิงก์เดิมจะใช้ได้ต่อ

## หลังติดตั้ง ทำทันที

1. เข้าเว็บแอป แท็บ **ผู้ดูแล** ใช้รหัสเริ่มต้น `admin1234`
2. ไปที่แท็บ **ตั้งค่า** เปลี่ยนรหัสผู้ดูแลใหม่ (อย่างน้อย 8 ตัวอักษร)
3. แท็บ **นำเข้าข้อมูล** คัดลอกรายชื่อนักศึกษาและครูจาก Excel มาวาง (ไม่ต้องมีแถวหัวตาราง)
   - นักศึกษา: รหัส | ชื่อ-สกุล | เบอร์โทร | ระดับชั้น | สาขาวิชา
   - ครู: รหัส | ชื่อ-สกุล | เบอร์โทร | แผนก

ลืมรหัสผู้ดูแล: เปิด Apps Script เลือกฟังก์ชัน `resetAdminPassword` แล้วกด Run รหัสจะกลับเป็น `admin1234`

## แผ่นงานที่ระบบสร้างใน Google Sheet

| แผ่นงาน | เก็บอะไร |
|---|---|
| นักศึกษา | รหัส ชื่อ-สกุล เบอร์โทร ระดับชั้น สาขา รหัสกลุ่ม (ข้อมูลลงทะเบียน) |
| ครูผู้สอน | รหัสครู ชื่อ-สกุล เบอร์โทร แผนก |
| กลุ่มโครงงาน | ชื่อโครงงาน ประเภท รูปแบบการจัด รายวิชา หน่วยการเรียนรู้ ครูผู้สอน |
| ความก้าวหน้า | สถานะ ผลงาน ลิงก์ และผลตรวจของครู ทีละขั้น (เส้นทาง P = ทำโครงงาน 6 ขั้น, R = เขียนเล่ม 11 ขั้น) |
| ตั้งค่า | รหัสผู้ดูแล (เข้ารหัสแบบแฮช) และจำนวนสมาชิกสูงสุดต่อกลุ่ม |
| บันทึกการใช้งาน | ประวัติการเข้าระบบและการบันทึกข้อมูล |

ข้อควรระวัง: อย่าเปลี่ยนชื่อแผ่นงานหรือชื่อหัวคอลัมน์ ระบบอ่านข้อมูลจากชื่อหัวคอลัมน์ (สลับลำดับคอลัมน์ได้ เพิ่มคอลัมน์ของตัวเองต่อท้ายได้)

## การใช้งานโดยย่อ

**นักศึกษา**
1. กรอกรหัสนักศึกษา ถ้าไม่มีในระบบ กรอกชื่อ-สกุลและเบอร์โทรเพื่อลงทะเบียน
2. เข้าครั้งแรก: อ่านบทเรียนและตอบคำถามให้ถูก 3 ข้อ > เลือกประเภทโครงงาน ใส่รายวิชาและหน่วยการเรียนรู้ ติ๊กหน่วยที่จัดแบบโครงงาน > เพิ่มสมาชิกด้วยรหัส (ถ้าเพื่อนยังไม่ลงทะเบียน กรอกชื่อและเบอร์ให้ได้) > เลือกครูผู้สอน (ถ้าไม่มีในรายการ เพิ่มครูใหม่ได้)
3. สมาชิกคนใดก็เข้าด้วยรหัสของตนเอง และเห็นงานของกลุ่มเดียวกัน
4. ทำงานทีละขั้น: คัดลอก Prompt (ระบบเติมชื่อโครงงาน รายวิชา หน่วย สมาชิกให้แล้ว ส่วนสีเหลืองให้แทนด้วยข้อมูลจริง) > บันทึกผลงานและลิงก์ > เปลี่ยนสถานะ
5. ขั้นที่มีตรา "ครูตรวจ" ให้เลือกสถานะ "ส่งครูตรวจ" ขั้นที่ 3 จะเปิดเมื่อครูอนุมัติขั้น 2.6 และขั้นที่ 4 จะเปิดเมื่อครูอนุมัติขั้น 3.7

**ครูผู้สอน**
- เข้าด้วยรหัสครู เห็นเฉพาะกลุ่มที่เลือกครูท่านนั้น เรียงกลุ่มที่มีงานรอตรวจไว้ก่อน
- เปิดแต่ละขั้นเพื่ออ่านผลงาน แล้วเลือก "ผ่าน / อนุมัติ" หรือ "ส่งกลับแก้ไข" พร้อมความเห็นและคะแนน (ถ้ามี)

**ผู้ดูแล**
- ดูภาพรวมทุกกลุ่มและแยกตามครู แก้ไขหรือลบข้อมูลนักศึกษา ครู กลุ่ม เปลี่ยนครูของกลุ่ม นำเข้ารายชื่อ ตั้งจำนวนสมาชิกสูงสุด และดูบันทึกการใช้งาน

## ข้อจำกัดที่ควรทราบ

- นักศึกษาและครูเข้าระบบด้วยรหัสอย่างเดียวตามที่กำหนด ผู้ที่รู้รหัสของผู้อื่นจะเข้าแทนได้ เหมาะกับการใช้ในชั้นเรียน ถ้าต้องการความปลอดภัยมากขึ้น ควรเพิ่มการยืนยันด้วยเลข 4 ตัวท้ายของเบอร์โทร
- Prompt ในแต่ละขั้นเขียนขึ้นตามโครงสร้างขั้นและขั้นย่อยของคู่มือ Prompt AI วิชาโครงงาน (ไม่ได้คัดลอกจากเล่ม) ครูแก้ไขข้อความได้ในไฟล์ `Index.html` ส่วน `P_STEPS` และ `R_STEPS`
- Google Apps Script รองรับผู้ใช้พร้อมกันได้ระดับชั้นเรียน (หลักสิบถึงร้อยคน) ระบบล็อกการเขียนทีละคำขอเพื่อป้องกันข้อมูลชนกัน
